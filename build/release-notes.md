A fast, modern and secure messenger for Windows PCs on the same office or site network. No server and no internet needed. English and Монгол.

## Download

| File | What it is |
|---|---|
| **LAN-Messenger-2-Setup-….exe** | Normal installer (recommended) |
| **LAN-Messenger-2-Portable-….exe** | Runs without installing, e.g. from a USB stick |

## Install

1. Run the Setup file on each PC.
2. If Windows shows **"Windows protected your PC"**, click **More info → Run anyway**. The app is safe; it just isn't signed with a paid certificate.
3. Choose **Install for all users** if you can, so the firewall rule is added automatically. Otherwise allow **LAN Messenger 2** on Private and Domain networks when Windows asks.

PCs running LAN Messenger 2 find each other automatically. Later versions spread between PCs over the network by themselves.

## Highlights

- Private, group and "Everyone" chats with reliable delivery, even to PCs that are switched off
- Urgent alerts that pop up over everything until acknowledged
- Voice and video calls, screen sharing, screenshots with drawing
- Files and whole folders by drag & drop
- Chess, Checkers, Tetris Battle and more inside chats
- 6 design styles in light and dark
- Stays in the taskbar corner when closed, starts with Windows
